# Exploratory Data Analysis of Smartphone Usage and Addiction

## Project Overview
This project analyzes smartphone usage patterns and explores their relationship with smartphone addiction using Python.

## Dataset
- 7,500 records
- 16 columns
- Includes screen time, social media usage, gaming hours, sleep hours, stress levels, and addiction levels.

## Tools and Libraries
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Project Workflow
1. Loaded and inspected the dataset.
2. Checked for missing values and duplicate records.
3. Examined data types and potential outliers.
4. Performed exploratory data analysis (EDA).
5. Created charts and visualizations.
6. Analyzed correlations and usage patterns.

## Key Findings
- Average daily screen time was approximately 7.5 hours.
- Users in the severe addiction category averaged approximately 8.60 hours of daily screen time.
- 3,344 records had more than 8 hours of daily screen time.
- Correlation analysis helped identify relationships between usage patterns and addiction indicators.

## Conclusion
This project demonstrates data cleaning, exploratory data analysis, visualization, and interpretation using Python.

**Note:** Correlation does not prove causation.
