# 📱 Smartphone Usage and Addiction Analysis

## 📌 Project Overview

The **Smartphone Usage and Addiction Analysis** project explores smartphone usage patterns and their relationship with addiction levels, screen time, social media usage, gaming habits, sleep, and stress.

Using Python and data analysis libraries, this project examines usage data, identifies patterns, and presents insights through data visualization. The analysis aims to improve understanding of smartphone usage behaviour and its potential relationship with daily habits and well-being.

## 🎯 Objectives

- Analyze smartphone usage patterns and screen time.
- Explore social media and gaming usage behaviour.
- Examine the relationship between smartphone usage, sleep, and stress.
- Compare usage patterns across different addiction levels.
- Identify trends, correlations, and potential outliers.
- Present meaningful insights using charts and visualizations.

## 🛠️ Tools and Technologies

- **Programming Language:** Python
- **Data Manipulation:** Pandas, NumPy
- **Data Visualization:** Matplotlib, Seaborn
- **Analysis Techniques:** Data Cleaning, Exploratory Data Analysis (EDA), Correlation Analysis, Outlier Detection, Feature Engineering

## 📂 Dataset Description

The project analyzes **7,500 smartphone usage records** to explore usage behaviour and addiction levels.

The dataset covers areas such as:

- Screen time
- Social media usage
- Gaming activity
- Sleep patterns
- Stress levels
- Smartphone addiction levels
